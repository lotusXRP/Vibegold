# VibeGold™

**VibeGold™** is a resonance-driven cannabis extraction technology and e-commerce platform that enables solvent-free or ethanol-assisted cymatic extraction of THC and terpenes for vapable concentrates.

This repo contains the full-stack implementation, including:
- **Frontend**: Next.js React website with Stripe/Uphold pre-order integration
- **Backend**: FastAPI server handling payments, order processing, and protocols

## Live Demo
Frontend: [https://vibegold.vercel.app](https://vibegold.vercel.app)  
Backend: [https://vibegold-api.onrender.com](https://vibegold-api.onrender.com)

---

## Features

- Cymatics-based protocol info and pre-order page
- Stripe + Uphold integration for crypto and fiat payments
- Custom logo, branding, and mobile optimization
- Backend API with FastAPI for secure checkout
